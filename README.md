# IDCraft Studio

Design, fill and print ID cards on Windows.

## Download

**[⬇ Download IDCraft Studio for Windows](https://github.com/Atharv96KOG1/IDCraftStudio-Download/releases/latest/download/IDCraft-Studio-Setup.exe)**

Works on Windows 10 and Windows 11 (64-bit, 32-bit and ARM PCs).

## How to install

1. Click the download link above and save the file.
2. Double-click **IDCraft-Studio-Setup.exe**.
3. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**.
4. Follow the installer. IDCraft Studio opens when it finishes and adds a desktop shortcut.

## What you can do

- Design ID cards (front and back) with text, photos, logos, shapes, QR codes and barcodes
- Add people one by one, or import a whole Excel / CSV sheet
- Attach photos in bulk by file name, or take photos with a webcam
- Print many cards per A4/Letter sheet with cut marks, or print on a card printer
- Save cards as PDF

All your data stays on your own computer.

## Uninstall

Windows Settings → Apps → IDCraft Studio → Uninstall.
