## How to install

**Windows**
1. Click the Windows download link above and save the file.
2. Double-click **IDCraft-Studio-Setup.exe**.
3. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**.
4. Choose the screen language and start the free trial (or enter your licence key) in the installer. IDCraft Studio opens when it finishes and adds a desktop shortcut.

**Mac**
1. Download the file for your Mac and open it.
2. Drag **IDCraft Studio** to **Applications**.
3. The first time, right-click the app in Applications and choose **Open**. If macOS still blocks it, go to **System Settings › Privacy & Security** and click **Open Anyway**.
